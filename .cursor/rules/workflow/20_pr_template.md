PR title must include the ticket number when available (e.g. `[TECNO-2288] Hide helpdesk for portal users`).

PR description must include: Summary, Changes, Test Steps, Risks. Risks should be brief: one of `security` | `accounting` | `reports` | `migrations` | `perf` | `none` (optionally one line of detail).

**Copyable template for PR description:**

```markdown
## Summary


## Changes


## Test Steps


## Risks

none
```
